# Apple wrist position feedback A/B

User approved a controlled comparison on the same ten apple positions from20261025_2022_four_task_positions. This is fresh-start fixed-policy testing, not another retry benchmark. Candidate0 is reused verbatim from each authenticated historical API batch. No new API calls, no parameter search, no manual candidate edits.

Baseline: original-token frames0..345, then mode1; existing source wrist references, scene shift, +5cm paired wrist Z correction during fixed contact interval, source hand timing, tail1.5s, native acceptance and safety remain fixed. Feedback: historical position_bias from humanoid_mimicgen/wrist_feedback.py, bias(t+1)=norm_clip(bias(t)+0.5*0.02*(desired-measured),0.02m). Desired is the baseline right wrist reference INCLUDING its fixed API offset and scene translation; measured is right_wrist_yaw_link origin in world metres. Only right wrist XYZ entering encoder changes. No orientation/left/torso/leg/reference-time/hand or postdecoder changes. Accumulation begins at first mode1 tick, not during the frozen token prefix, and continues through the same tail.

This restores the historical integral formula, not historical approach/navigation/early-finger/recovery behavior. Fixed source references already incorporate an empirical correction; this experiment tests integrating their tracking error and does not assert those references are the unique correct physical goal. No retuning if results worsen. Successful fresh rollouts are independently replayed with recorded tokens and final hand commands, feedback disabled. Raw decoder body PD identity audited. Failed rollouts retained. Fresh baseline must match historical seed exactly and both arms must match through unchanged prefix. Hands and nominal reference targets compared on common executed frames. RMSE on full suffix and common suffix reported; truncated safety failures separated.

Complete-state rollback of this added integral is outside this comparison. Feedback runs publish checkpoint manifest version2 to reject legacy version1 rollback loaders; saved-token full replay remains supported. Baseline checkpoint export unchanged. Source, old feedback helper, config, protocol, models/providers and exact physical scene are bound before physics by runtime and scoped evidence hooks. Feedback hooks and runtime alias restored on exit; suite_evidence installation is process-wide, so use the process-isolated CLI.
