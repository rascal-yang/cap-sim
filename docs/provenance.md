# 来源与依赖边界

本仓库是 G1 苹果实验管线的工程封装。实验原则来自当前项目讨论：错误分析先于重试、部分成功前缀保留、先完整成功再优化、同一控制接口、固定物理／验收、重放初态、分别评估有／无参考。

核心和便携示例的源码在此仓库。`backends/g1_worker.py` 通过外部实验提供的 `runtime.py`、`base_runtime.py`、`sonic_controller.py`、`policy.py` 调用控制器；不复制其完整运行时。外部 SONIC ONNX、G1/Dex3 模型、HUMANO parquet 和原始视频不随仓库分发，使用者自行准备并遵循各自授权条款。G1 历史运行时中仍有机器路径假设，迁移机器可能需要单独整理该依赖；不能只克隆此库就宣称拥有完整 G1 系统。

HUMANO 的原始苹果／厨房资产未取得。历史实验用近似几何，正向运动学导入得到的是该兼容场景下的几何估计；不是原数据接触真值。视频资产清单必须标记 measured/fitted/estimated/designed，视觉外观、纹理、物理和尺度校准分别报告。

`demo` 规划器是确定性测试夹具，测试不能用来报告 GPT 成功率。`OpenAIPlanner` 接官方 Responses 的文本／图像请求形式，接口测试采用 mock，不表示已调用在线模型。复杂视频网格重建只提供可信外部命令协议。

未包含 API key、下载令牌、模型权重、下载数据或历史实验目录。当前只建立本地 Git 仓库；没有向远程平台发布。
