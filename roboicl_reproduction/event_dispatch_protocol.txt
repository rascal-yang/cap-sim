One newly spawned fork_turns=none planner per experiment, expected identity frozen in planner_birth.json. The same agent handles every decision and can remember only current-episode requests/results plus supplied measured TRAIN. No prior experiment result, reflection, repository source, raw trajectory or parent conversation access. This is instruction isolation on a shared filesystem, not an OS sandbox.
The planner reads each request and its images, reasons about the action, writes exactly one raw response atomically. Then write NNN_response.provenance.json containing request_sha256,response_sha256,agent,fork_turns=none,episode_id,turn_index,previous_response_sha256,history_scope=current_episode_only,recorded_at. Then atomically publish NNN_ready.json. Never modify response after ready. The hashes chain responses across the same episode and the runner enforces the same exact agent identity.
The agent may use a polling loop solely to await the next request or done.json; every new action/explicit wait decision must be generated by the model from LIVE, never a scripted action policy or source replay. Stop on done.json; fail transport explicitly if unable. No coordinator substitutes or edits actions. Initial spawn identity/time is recorded separately by the root before freeze.
